================================================================================
                     HOW TO TEST SATQUERY RIGHT NOW
================================================================================

You're currently in the CLI and it's asking for an image path.
Here's exactly what to do:


OPTION 1: TEST WITH CLI (Easiest - You're already here!)
================================================================================

STEP 1: Type 'cancel' to exit the current prompt
--------------------------------------------------------------------------------
In your CLI window, type:
   cancel

Then press Enter.


STEP 2: Exit the CLI and start the API server first
--------------------------------------------------------------------------------
Select option: 3 (Exit)

Then open a NEW terminal and run:
   start_server.bat

OR manually:
   venv\Scripts\activate
   python main.py

WAIT until you see: "Uvicorn running on http://0.0.0.0:8000"


STEP 3: Open another terminal and run CLI again
--------------------------------------------------------------------------------
   start_cli.bat

OR manually:
   venv\Scripts\activate
   python cli.py


STEP 4: Select option 1 (Process new query)
--------------------------------------------------------------------------------


STEP 5: Enter the image path
--------------------------------------------------------------------------------
When it asks "Enter image path (or 'cancel' to return):", type:

   data/raw/test_satellite_image.png

Then press Enter.


STEP 6: Enter your query
--------------------------------------------------------------------------------
When it asks "Enter your query:", type:

   How many buildings are visible in this image?

Then press Enter.


STEP 7: View the results!
--------------------------------------------------------------------------------
You should see formatted results with:
- Answer
- Confidence score
- Tool used
- Detailed information
